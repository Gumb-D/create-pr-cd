## 🎯 Skill Understanding

### Purpose
Generate CelcomDigi TX PR ECC files from site-level PR/PO data by:
1. Reading site data reference
2. Matching sites to correct PR models
3. Retrieving contract and purchasing information
4. Generating ECC output files
5. Preventing duplicate PR generation
6. Flagging ambiguous cases as REVIEW_REQUIRED

### TSS PR Scope (What We Validated)
- **Trigger:** SubCon - TSS Team is not blank
- **Matching:** Use Tx SOW only (antenna size NOT required)
- **Quantity:** Always 1 per site per line item
- **Grouping:** By Region + Subcontractor
- **File Format:** ECC 14-column format
